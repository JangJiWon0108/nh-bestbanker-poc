# 「NH Best Banker 2025」 제도 평가항목별 세부평가기준 - 디지털금융

## [공통 적용 기준] (디지털금융)
- 개인고객(개인사업자포함) : 고객구분코드 1100 ~ 2100
- 법인고객 : 상기 개인(개인사업자포함)고객을 제외한 고객
- 각 평가사업별 배점의 130%까지 초과득점 평가 반영(단, 100%초과 ~ 150%이내 득점은 3/5 반영)

### 평점산출방식
- 개인디지털금융 산출기준 (디지털금융)
|   |   |
|---|---|
|구분|산출기준|
|NH올원뱅크|▪ 신규가입 + 로그인|
|**NH모바일인증서**|▪ **최초발급(NH올원뱅크 내 발급만 인정)**|
|NH손하나로 인증|▪ 신규가입 + 계좌등록 + **최초인증**|

|오픈뱅킹|▪ 오픈뱅킹 등록(타행계좌, 카드, 핀테크 선불 계정)|
|NH멤버스|▪ 신규가입 + 로그인 + 마케팅동의※ ※ 마케팅동의 : 수집·이용·제공 **동의** + 채널수단 中 **최소 1건 이상 설정**(채널수단 : TM, DM, SMS, e-mail, push)|

|   |   |
|---|---|

|하나로sERP|▪ 신규가입+프로그램설치+정상이용실적(금융이체 3회이상) ※ 금융이체: 즉시이체(건별1회), 대량/급여(파일당1회) ※ 매월 로그인이력 없을시 실적제외|
|NH기업스마트뱅킹|▪ 신규가입 + 로그인|
